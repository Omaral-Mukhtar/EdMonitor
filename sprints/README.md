## Cross-Sprint Invariants (Never Violate)

1. **Zero external 3D assets**: Procedural R3F primitives only; `<Canvas frameloop="never">` when overlays or hidden tabs are active.
2. **Single webcam stream**: `useSharedMedia` acquires `getUserMedia` once per room entry; LiveKit receives `baseVideoTrack.clone()`.
3. **100% client-side CV**: Self-hosted `/public/models/*`, 3–5 FPS loop, 3-second grace state machine, `yellow` break exemption.
4. **Double SVG sanitization**: Strip dangerous markup on the server (`POST /api/ai/whiteboard`) **and** via `DOMPurify` on every receiving client before DOM injection.
5. **Unified whiteboard space**: `1200 × 800` virtual canvas coordinates and `<svg viewBox="0 0 1200 800">`; separate `whiteboard:ai_overlay` and `whiteboard:ai_step` Broadcast events.
6. **Standalone `/ta-scheduler`**: Zero WebGL, R3F, LiveKit, or CV imports; Postgres `btree_gist` 3-way conflict blocking.
